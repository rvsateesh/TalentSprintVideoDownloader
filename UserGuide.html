TalentSprint Video Downloader

A simple Python utility to inspect a TalentSprint lesson page and download direct video files or HLS streams.

Step 1 - Prerequisites

Requirements

This project needs Python and a few libraries. The easiest setup is:

  1. Install Python 3.9+ on your system.
  2. Open a terminal in the project folder.
  3. Install project dependencies:
python -m pip install -r requirements.txt
If you are on Windows, you can use a Command Prompt or PowerShell window. If you are using a virtual environment, activate it first before running the install command.
Step 2 - Project Files

What is inside the project

The folder contains:

  • download_talentsprint.py – the main script that scans a TalentSprint lesson page and downloads the video.
  • requirements.txt – Python packages required for the script.
  • downloads/ – default output directory for downloaded files.
  • README.md – quick usage reference.

Open your terminal in the same folder as the script and then run the commands below.

Step 3 - Basic usage

Download a lesson page

To download media from a TalentSprint page, provide the lesson or page URL.

python download_talentsprint.py "https://example.com/lesson" -o my_videos

If the page requires login, send the cookie header too:

python download_talentsprint.py "https://example.com/lesson" --cookie "sessionid=your_session_cookie" -o my_videos

If you already saved your cookie in a text file, you can use that instead:

python download_talentsprint.py "https://example.com/lesson" --cookie-file cookies.txt -o my_videos
The URL must be the full URL with https://. Do not use a placeholder or partial URL.
Step 4 - Getting cookies

How to get the authentication cookie

If the TalentSprint lesson page is protected, you must use a valid login cookie. The script supports that through the --cookie or --cookie-file option.

  1. Open the TalentSprint site in your browser.
  2. Log in normally.
  3. Open browser Developer Tools: F12.
  4. Go to the Application or Storage tab.
  5. Select Cookies and open the TalentSprint domain.
  6. Find the session cookie name such as sessionid, connect.sid, or similar.
  7. Copy the value and pass it to the script.
--cookie "sessionid=abcd1234xyz"

Example with multiple cookies:

--cookie "sessionid=abcd1234xyz; csrftoken=xyz987; othercookie=value"
Step 5 - HLS / M3U8 videos

Downloading an HLS stream

If the page exposes an HLS playlist ending in .m3u8, the script uses FFmpeg to download the stream.

python download_talentsprint.py "https://example.com/lesson-with-hls" --ffmpeg "C:\ffmpeg\bin\ffmpeg.exe" -o downloads

If FFmpeg is installed and available in your PATH, you can simply run:

python download_talentsprint.py "https://example.com/lesson-with-hls" -o downloads
The script will detect candidate links such as .mp4 or .m3u8, print them, and let you choose the correct source if more than one is found.
Step 6 - Installing FFmpeg

Install FFmpeg

For HLS playlists, FFmpeg is recommended. Install it and ensure the ffmpeg command works in your terminal.

Windows:

  • Download FFmpeg from https://www.ffmpeg.org/download.html
  • Extract it and add the bin folder to PATH.
  • Verify by running:
ffmpeg -version

If FFmpeg is not in PATH, pass the full path explicitly:

python download_talentsprint.py "https://example.com/lesson-with-hls" --ffmpeg "C:\ffmpeg\bin\ffmpeg.exe"
Step 7 - Finding the correct URL

Where to get the page or asset URL

The script works best when you provide the actual page URL that contains the video. If the page loads the video through JavaScript or a CDN, the script may not find it automatically.

  1. Open the TalentSprint lesson in the browser.
  2. Open Developer Tools (F12).
  3. Go to the Network tab.
  4. Filter for m3u8, mp4, or video.
  5. Look for a direct media URL in the request list.
  6. Copy the URL and use it in the command.
python download_talentsprint.py "https://cdn.example.com/video/master.m3u8" --cookie "sessionid=your_cookie"
Sometimes the direct media URL requires the original page as Referrer. In that case, pass the page URL with the --referer option.
Step 8 - Example command flow

Typical workflow

  1. Open the TalentSprint lesson.
  2. Copy the lesson URL.
  3. Log in and copy cookies if required.
  4. Run the script with the URL and cookie.
  5. Check which media source is found.
  6. Let the script save the file in the output folder.
python -m pip install -r requirements.txt
python download_talentsprint.py "https://talentsprint.example.com/lesson/123" --cookie "sessionid=abc123" -o downloads

If the lesson is HLS-based:

python download_talentsprint.py "https://talentsprint.example.com/lesson/123" --cookie "sessionid=abc123" --ffmpeg "C:\ffmpeg\bin\ffmpeg.exe" -o downloads
Step 9 - Troubleshooting

If it does not work

  • Check that the URL uses https://.
  • Make sure you are logged in and your cookie is valid.
  • Use the browser Network tab to find the actual .m3u8 or .mp4 link.
  • If FFmpeg is missing, install it and add it to PATH.
  • If the page uses JavaScript-heavy content, you may need to copy the direct media URL manually and pass it to the script.
Some sites use DRM or protected media. If the stream is encrypted, the script may need additional credentials or a browser/player that supports the DRM flow. In that situation, direct scraping may not be possible.
